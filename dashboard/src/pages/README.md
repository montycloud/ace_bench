# dashboard/src/pages/

Top-level routed views for the dashboard.

- **`Dashboard.jsx`** — L1 / L2 summary and scores by category
- **`Runs.jsx`** — all scenarios by category with run history, filterable by L1 / L2 / All
- **`RunDetail.jsx`** — full breakdown for a single run: tool call timeline, resource coverage, fidelity score
