# dashboard/src/components/

Shared, reusable React components used across the dashboard pages.

- **`PillarScores.jsx`** — renders the Tools/Answer/Safety/Output (+ Fidelity) pillar breakdown for a run
- **`ScoreBar.jsx`** — horizontal bar visualization for a score value
- **`ScoreChip.jsx`** — small colored chip/badge summarizing a score or status
- **`PromptModal.jsx`** — modal dialog for viewing the full scenario prompt
