# ACE Bench Dashboard

React + Vite frontend for visualizing ACE Bench scenario run results.

## What it shows

Data is read from `public/data/`, which is populated by `runner/run.py` (per-run results),
`runner/llm_judge.py` (fidelity judge findings), and `runner/report.py` (aggregate
per-scenario reports). Nothing in the dashboard talks to AWS or the agents directly — it's
a static read of whatever JSON has been generated by the Python pipeline.

- **Dashboard** (`src/pages/Dashboard.jsx`) — L1 / L2 summary, scores by category
- **Runs** (`src/pages/Runs.jsx`) — all scenarios by category with run history, filterable by L1 / L2 / All
- **Run detail** (`src/pages/RunDetail.jsx`) — full breakdown for one run: tool call timeline, resource coverage, fidelity score

## Data layout

```
public/data/
├── index.json          # Summary row per run, rebuilt after every runner.run invocation
├── results/            # Symlink to runner/result/{agent}/ — {scenario_id}__{agent}__{timestamp}.json
└── reports/             # Aggregate per-scenario reports (runner.report --all)
```

## Running locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. See the root [README](../README.md) for how to generate the
underlying run data.

## Build

```bash
npm run build
```

Built with Vite + React 19 + Tailwind CSS + Recharts.
