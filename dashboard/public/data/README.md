# dashboard/public/data/

Data consumed by the dashboard frontend. Nothing here is hand-written — it's all generated
by the Python pipeline in `runner/`.

- **`index.json`** — summary row per run, rebuilt after every `runner.run` invocation
- **`results/`** — symlink to `runner/result/{agent}/` — one JSON file per run, named `{scenario_id}__{agent}__{timestamp}.json`
- **`reports/`** — aggregate per-scenario reports generated by `runner.report --all`
